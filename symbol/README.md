# Symbol

Monogramul Product Makers — logo-ul comprimat într-un singur tile, pentru
locurile în care lockup-ul "PRODUCT Makers" ar fi ilizibil: browser tab,
favicon, avatar de Slack sau LinkedIn, icon pe home screen.

Nu înlocuiește logo-ul. Unde încape logo-ul întreg, folosește
[logo-ul](../logo/).

| Fișier | Când îl folosești |
| --- | --- |
| [`product-makers-symbol.svg`](product-makers-symbol.svg) | Varianta default, cu colțuri rotunjite. Oriunde tile-ul se vede așa cum e. |
| [`product-makers-symbol-512.png`](product-makers-symbol-512.png) | Aceeași, ca PNG 512 × 512 — pentru upload de avatar, unde SVG nu e acceptat. |
| [`product-makers-symbol-square.svg`](product-makers-symbol-square.svg) | Full-bleed, fără colțuri rotunjite. Pentru platformele care aplică ele mask-ul (iOS, unele profile rotunde). |

| [`favicon.ico`](favicon.ico) | Gata de pus pe orice site Product Makers. Conține 16, 32 și 48 px, fiecare desenat la dimensiunea lui. |

## Ce e în el

Un ligature "PM": M-ul din scriptul *Makers* călare peste P-ul geometric din
*PRODUCT*, alb pe albastru de brand `#3f3fff`, plat (fără gradient — la
dimensiunea unui tab, gradientul se face noroi).

Ambele litere sunt curbe reale, decupate din logo, nu litere culese cu un font.
M-ul are un knockout albastru pe unde trece peste P: fără el cele două se
lipesc într-o singură pată albă, P-ul își pierde bucla și monogramul se citește
"FM".

Nu-l recolora, nu-l întinde, nu-i schimba proporțiile între litere și nu pune
altceva în tile. Regulile complete sunt în
[`DESIGN.md`](../DESIGN.md) — secțiunea *The symbol mark (app icon)*.
